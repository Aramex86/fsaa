Worked example — accounting table

One real module from the production tool: a financial accounting table, sliced end to end.

File tree

Key rule

The table component stays generic; business-specific columns live in their features. If two entities need the same visual pattern, extract the pattern into shared, keep entity configuration in features.

shared — the generic molecule

The table itself is domain-free. It graduated early because several pages and features render tabular data.

features — the business configuration

Column definitions know money, accounts and periods — that is why they are a feature, not a shared molecule.

pages — route-level composition
