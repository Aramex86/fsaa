In practice · FSAA docs

FSAA vs other approaches

FSAA borrows deliberately: layers from FSD, vocabulary from Atomic Design, pragmatism from Bulletproof React.

The hybrid answer

“Isn’t this just FSD + Atomic?” — Yes, deliberately. The value is not novelty, it is the missing decision rules: the graduation pattern, the boundary test for shared, and the removal of organisms. We do not claim a revolution.

Taken from FSD

  • ✅ Sliced layers with strict downward imports
  • ✅ Entities hold models and data access
  • ✅ Public API via index.ts per slice

Taken from Atomic Design

  • ✅ atoms/molecules vocabulary inside shared/ui
  • ✅ Small, composable, generic UI building blocks
  • ✅ A shared language for primitives everyone knows
